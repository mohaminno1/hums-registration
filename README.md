# راهنمای روز ثبت‌نام دانشجویان نوورودی (دندانپزشکی و داروسازی)

وب‌سایت راهنمای سبک، فوق‌سریع و کاملاً بدون وابستگی خارجی (**Zero-Dependency**) برای استفاده روی موبایل در روز ثبت‌نام و میزبانی رایگان روی **GitHub Pages**.

## ساختار فایل‌ها

- `index.html`: ساختار معنایی صفحه (راست‌به‌چپ فارسی)
- `css/styles.css`: سیستم طراحی مینیمال کاغذی و استایل چاپ (`@media print`)
- `js/data.js`: **تنها فایلی که برای تغییر محتوا نیاز به ویرایش دارد**
- `js/app.js`: منطق چک‌لیست، فلوچارت، نقشه، فیلترها و ذخیره وضعیت در مرورگر
- `fonts/`: محل قرارگیری فونت فارسی Self-Hosted
- `assets/`: محل قرارگیری نقشه دانشگاه

---

## ۱. نحوه به‌روزرسانی محتوا (حتی با موبایل از GitHub)

تمام متن‌ها، مدارک، مراحل ثبت‌نام، تابلوی وضعیت، تشکل‌ها و سوالات متداول در فایل `js/data.js` قرار دارند:

1. در مخزن GitHub، فایل `js/data.js` را باز کرده و روی آیکون مداد (Edit) بزنید.
2. متن داخل گیومه‌ها (`"..."`) را ویرایش کنید. بالای هر بخش کامنت فارسی راهنما نوشته شده است.
3. برای تغییر وضعیت یک موضوع در **تابلوی وضعیت**، مقدار `state` را به یکی از سه حالت زیر تغییر دهید:
   - `"confirmed"` (سبز — قطعی)
   - `"pending"` (زرد — در حال بررسی)
   - `"unknown"` (خاکستری — نامشخص)
4. دکمه **Commit changes** را بزنید؛ سایت ظرف ۱ تا ۲ دقیقه روی GitHub Pages به‌روز می‌شود.

> **نکته:** اگر لیست مدارک یا مراحل را به‌کلی تغییر دادید، مقدار `storageVersion` در ابتدای `js/data.js` را (مثلاً از `"v1"` به `"v2"`) تغییر دهید تا چک‌لیست کاربران به‌صورت خودکار با فهرست جدید هماهنگ شود.

## ۲. اضافه کردن فونت فارسی (`Vazirmatn FD`)

برای سرعت بارگذاری عالی و عدم وابستگی به CDN خارجی، فونت به‌صورت Self-Hosted تعریف شده است:

1. آخرین نسخه فونت [Vazirmatn](https://github.com/rastikerdar/vazirmatn/releases) را دانلود کنید.
2. از پوشه `misc/Farsi-Digits/fonts/webfonts/` فایل `Vazirmatn-FD[wght].woff2` را کپی کرده و دقیقاً در پوشه `fonts/` همین پروژه قرار دهید:
   ```text
   fonts/Vazirmatn-FD[wght].woff2
   ```

---

## ۳. جایگزینی نقشه واقعی دانشگاه

فعلاً یک نقشه شماتیک سبک (`assets/campus-map.svg`) نمایش داده می‌شود. هر زمان عکس واقعی نقشه دانشگاه آماده شد:

1. تصویر بهینه‌شده نقشه را با نام `campus-map.webp` در پوشه `assets/` قرار دهید.
2. در فایل `js/data.js` بخش `map`، مقدار `imageUrl` را تغییر دهید:
   ```js
   imageUrl: "assets/campus-map.webp",
   ```
3. شماره‌های بخش `map.pins` را با شماره‌های روی نقشه جدید هماهنگ کنید.

---

## ۴. انتشار روی GitHub Pages

1. فایل‌ها را در مخزن GitHub خود Push کنید.
2. به مسیر **Settings → Pages** بروید.
3. در بخش **Build and deployment**، گزینه Source را روی `Deploy from a branch` و شاخه را روی `main` (پوشه `/root`) قرار دهید و Save کنید.
